---
description: Stop-and-reassess — use when something feels wrong but you can't articulate why
---

Something feels off. Before we continue:

1. Summarize what you think we're trying to accomplish right now.
2. Summarize what you've done so far this session.
3. List any assumptions you made that I didn't explicitly confirm.
4. List anything that's not working as expected.
5. Propose: should we continue the current approach, try a different one, or stop and reassess?

Don't write any code until we've sorted this out.
