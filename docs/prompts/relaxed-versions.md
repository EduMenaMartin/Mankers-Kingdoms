# Relaxed Prompts

Use these after ~5-10 sessions once the pattern is muscle memory.
Switch back to the strict versions (other files in this folder) if Claude starts skipping steps.

---

## Session start (relaxed)

Read HANDOVER.md and TODO.md. What are we working on and what's the next step?

---

## Session end (relaxed)

Wrap up: update HANDOVER, TODO, and any other rolling files. Prep a commit message with multiple -m flags. Don't commit.

---

## Mid-task (relaxed)

Plan first, then implement. What files, what approach, what tests?
