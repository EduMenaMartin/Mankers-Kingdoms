# Claude Code Session Prompts

Copy-paste these into Claude Code at the right moment. They're versioned in the repo so they evolve with the project.

| File | When to use |
|---|---|
| `session-start.md` | Beginning of every Claude Code session |
| `session-end.md` | End of every session, before closing |
| `mid-task.md` | Before starting any new task (plan first) |
| `milestone-complete.md` | When finishing an M-number milestone |
| `weekly-retro.md` | Every Friday (or whenever), 15 min review |
| `when-stuck.md` | When something feels wrong but you can't say why |
| `relaxed-versions.md` | Shorter versions of start/end/mid once the pattern is habitual |

## Tips

- **First 5-10 sessions:** use the strict versions (individual files). They're verbose on purpose — they calibrate Claude Code's behavior.
- **After that:** switch to the relaxed versions. Switch back if Claude starts skipping steps.
- **Rider Live Templates:** if you want even faster access, set up abbreviations in Rider (Settings → Editor → Live Templates) like `ss` → session start, `se` → session end.
